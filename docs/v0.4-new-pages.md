## 设计字段与后端差距

以下字段在 mockup 里出现，但当前服务端没有公开，界面按真实数据展示并给出说明：

- 技能：「被 N 个 Bot 使用」、使用次数、历史版本。服务端只保存当前版本，也没有按技能统计 Bot 分配数的公开接口。
- 例程：来源对话、最近 5 次运行结果。`to_dict()` 只返回 `next_run_at` / `last_run_at`。
- 出站草稿：目标显示名。`dest` 里可能只有 `chat_id` / `conversation_id` / `touser`，没有统一的好友或群名。
- 邮箱连接器：保存后的 IMAP/SMTP 主机、端口、SSL 无法读回。公开状态只有账号与是否连接。
- 日历连接器：安装时的超时秒数不在公开状态里，重新进入页面无法回显上次设置。
- 浏览器：镜像地址、权限模式没有接口；只展示服务器探测到的 MCP 服务信息。
- 通道：Bot 归属、回调地址、消息加密方式只在服务器 `.env`，App 不可读写。
- Page 作者：只有 `bot_id`，没有 Bot 显示名；界面统一显示「Bot」。
- 保管库支付卡：没有 reveal 接口，列表只展示 `last4`、品牌、有效期。
- 聊天「例程创建」卡：后端没有对应的消息类型，由客户端在每轮结束后对比例程列表生成；换设备后历史聊天里不会保留这张卡。
- Android 12 以下没有系统级 RenderEffect 模糊，弹层退回半透明遮罩；低端机不做关闭模糊的降级，Android 12+ 始终真实模糊。

## 真机手动验收清单

1. 设置 → 服务器填可访问的地址，登录后确认首页不报错。
2. 对话里让 Bot 执行一条需要审批的命令，确认聊天内出现工具审批卡；允许 / 拒绝后卡片变成结果行。
3. 让 Bot 往飞书或企业微信发一条消息并命中出站规则，确认出现出站草稿审批卡；到「设置 → 待发送草稿」确认同一条草稿，允许后状态变为已发送。
4. 在对话里说「每周一早上九点提醒我」，确认出现「Bot 创建了例程」卡；点「查看」打开例程详情，改时间后保存，回到例程 Tab 确认更新。
5. 例程 Tab 关闭 / 打开开关；再打开详情暂停、删除（删除前有二次确认）。
6. 子任务 Tab 派一个子任务，确认进行中分组与停止按钮；完成后进入已结束分组。
7. 打开底部任意弹层，确认背景是真实模糊（Android 12+），拖动 / 关闭动画不卡顿。
8. 技能库新建、编辑、停用、删除；确认列表和详情字数与版本号显示正常。
9. 连接应用 → 邮箱：填 IMAP/SMTP、应用专用密码，保存并测试；确认密码不会被读回。日历分别测试 CalDAV 与 ICS。
10. 通道状态页确认飞书 / 企业微信 / 钉钉的缺失环境变量与最近错误；浏览器页确认探测状态。
11. 共享记忆修改资料、添加与删除随手记；返回设置确认统计数字变化。
12. Pages 新建 / 编辑 / 公开 / 取消公开 / 复制链接 / 删除；在浏览器打开公开链接。
13. 保管库：本地条目正常；服务器保管库点开一条登录信息，点显示密码，确认取回成功且每次都有审计记录。
14. 断网或填错服务器地址，确认每个新页面都有错误文案和「重试」。
