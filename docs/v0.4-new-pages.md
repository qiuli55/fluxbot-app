## 账号系统（Flux Cloud）

App 的账号身份来自 Flux 账号云，默认地址 `https://flux.qiuli55.top`（路由前缀 `/api/auth`）。它与 Flux Bot 服务器地址（默认 `https://flux.qiuli55.top/bot`）相互独立：设置 →「账户 → 账号服务器」（登录页底部的账号服务器链接）只修改账号云地址，不改 Bot 地址。

主要文件：

| 文件 | 职责 |
| --- | --- |
| `data/CloudClient.kt` | 账号云 HTTP 客户端；只做请求与错误映射 |
| `data/CloudModels.kt` | 用户 / 令牌 / 校验模型，`org.json` 手工解析与表单校验 |
| `data/CloudAuthManager.kt` | 登录态、持久化、提前刷新、401 单飞刷新与重试、退出 |
| `data/SecureCloudTokenStore.kt` | 用 Keystore 加密的 `SecureStore` 保存整套 session |
| `data/CloudSettings.kt` | 账号服务器地址（`fluxbot.cloud` SharedPreferences） |
| `data/HttpTransport.kt` | 可替换的 HTTP 传输层，生产用 `HttpURLConnection`，单测用假实现 |
| `screens/AuthScreen.kt` | 登录 / 注册页，沿用现有 Flux 视觉规范 |
| `nav/Sheets.kt` | 账号服务器地址弹层 `Sheet.CloudServer` |

接口：

| 用途 | 接口 | 说明 |
| --- | --- | --- |
| 登录 | `POST /api/auth/login/token` | 请求 `{identifier, password}`，返回 access / refresh token、`expires_in` 与用户 |
| 注册 | `POST /api/auth/register` | 请求 `{email, password, username?, display_name?}`；响应体不下发令牌 |
| 注册后登录 | `POST /api/auth/login/token` | 注册成功后客户端立即用同一组凭据登录 |
| 刷新 | `POST /api/auth/token` | 请求 `{refresh_token}`，返回新的 access token |
| 当前用户 | `GET /api/auth/me` | Bearer access token；返回用户、第三方身份与 providers |
| 第三方登录探测 | `GET /api/auth/providers` | 无需登录；当前只用于设置页探测地址 |
| 退出 | `POST /api/auth/logout` | 仅 Cookie 会话可吊销，原生客户端只做尽力调用 |

流程：

1. **登录**：表单校验 → `login/token` → 令牌写入加密存储 → 创建本地账户 `cloud-<user.id>` → 后续 Flux Bot 请求带 `Authorization: Bearer <access token>`。
2. **注册**：`register` 成功后立刻 `login/token`；注册成功但自动登录失败时提示「注册成功，但自动登录失败，请改用登录」。
3. **冷启动**：`Store` 从 `SecureStore` 读取 `cloud.session`；存在且未过期就直接恢复账户，随后按需续期。
4. **提前刷新**：access token 到期前 120 秒自动刷新；每次刷新后重新排程。
5. **401 处理**：请求收到 401 → 单飞刷新（同一个失效 token 只刷一次）→ 原请求重试一次；刷新返回 401/403 或 token 已过期 → 清除本机 session 并回登录页。
6. **退出**：立即清除本机加密令牌并切换为未登录；服务端退出调用是尽力而为，失败不影响本地退出。

鉴权优先级：当前账户是 Flux Cloud 账户时使用云 access token；演示账户 / 旧设备令牌照旧使用原来的设备 token，互不覆盖。

已知差距：

- `/api/auth/logout` 只识别 Cookie，没有用 body 里的 refresh token 吊销会话的原生入口。退出后本机令牌立即删除，但服务端 refresh token 默认仍有效到过期（30 天）。
- `providers` 已能探测 GitHub / Google 是否开启，但本轮只实现密码登录与注册，第三方 OAuth 未接入。
- 注册后的邮箱验证、`must_change_password` 强制改密流程取决于账号云策略；App 只解析字段，尚未提供改密页。
- 账号云没有公开的会话列表 / 踢出其他设备接口。

## 设计字段与后端差距

以下字段在 mockup 里出现，但当前服务端没有公开，界面按真实数据展示并给出说明：

- 技能：「被 N 个 Bot 使用」、使用次数、历史版本。服务端只保存当前版本，也没有按技能统计 Bot 分配数的公开接口。
- 例程：来源对话、最近 5 次运行结果。`to_dict()` 只返回 `next_run_at` / `last_run_at`。
- 出站草稿：目标显示名。`dest` 里可能只有 `chat_id` / `conversation_id` / `touser`，没有统一的好友或群名。
- 邮箱连接器：保存后的 IMAP/SMTP 主机、端口、SSL 无法读回。公开状态只有账号与是否连接。
- 日历连接器：安装时的超时秒数不在公开状态里，重新进入页面无法回显上次设置。
- 浏览器：镜像地址、权限模式没有接口；只展示服务器探测到的 MCP 服务信息。
- 通道：Bot 归属、回调地址、消息加密方式只在服务器 `.env`，App 不可读写。
- Page 作者：只有 `bot_id`，没有 Bot 显示名；界面统一显示「Bot」。
- 保管库支付卡：没有 reveal 接口，列表只展示 `last4`、品牌、有效期。
- 聊天「例程创建」卡：后端没有对应的消息类型，由客户端在每轮结束后对比例程列表生成；换设备后历史聊天里不会保留这张卡。
- Android 12 以下没有系统级 RenderEffect 模糊，弹层退回半透明遮罩；低端机不做关闭模糊的降级，Android 12+ 始终真实模糊。

## 真机手动验收清单

1. 设置 → 服务器填可访问的地址，登录后确认首页不报错。
2. 对话里让 Bot 执行一条需要审批的命令，确认聊天内出现工具审批卡；允许 / 拒绝后卡片变成结果行。
3. 让 Bot 往飞书或企业微信发一条消息并命中出站规则，确认出现出站草稿审批卡；到「设置 → 待发送草稿」确认同一条草稿，允许后状态变为已发送。
4. 在对话里说「每周一早上九点提醒我」，确认出现「Bot 创建了例程」卡；点「查看」打开例程详情，改时间后保存，回到例程 Tab 确认更新。
5. 例程 Tab 关闭 / 打开开关；再打开详情暂停、删除（删除前有二次确认）。
6. 子任务 Tab 派一个子任务，确认进行中分组与停止按钮；完成后进入已结束分组。
7. 打开底部任意弹层，确认背景是真实模糊（Android 12+），拖动 / 关闭动画不卡顿。
8. 技能库新建、编辑、停用、删除；确认列表和详情字数与版本号显示正常。
9. 连接应用 → 邮箱：填 IMAP/SMTP、应用专用密码，保存并测试；确认密码不会被读回。日历分别测试 CalDAV 与 ICS。
10. 通道状态页确认飞书 / 企业微信 / 钉钉的缺失环境变量与最近错误；浏览器页确认探测状态。
11. 共享记忆修改资料、添加与删除随手记；返回设置确认统计数字变化。
12. Pages 新建 / 编辑 / 公开 / 取消公开 / 复制链接 / 删除；在浏览器打开公开链接。
13. 保管库：本地条目正常；服务器保管库点开一条登录信息，点显示密码，确认取回成功且每次都有审计记录。
14. 断网或填错服务器地址，确认每个新页面都有错误文案和「重试」。
15. 账号登录：在登录页用邮箱 / 用户名 + 密码登录，确认进入首页；杀掉进程重开，确认仍是登录态（不需要重新输入密码）。
16. 注册：切到「注册」，填邮箱、可选用户名 / 显示名称、至少 8 位密码，确认注册成功后自动登录；再用同一邮箱注册一次，确认显示服务端「该邮箱已注册」文案。
17. 登录失败：故意输错密码，确认页面展示账号云返回的中文错误；断网时确认提示无法连接账号服务器。
18. 令牌刷新：把账号服务器 access TTL 调到 3 分钟以内，登录后放置到临近过期，再操作 Bot / 打开设置，确认请求不跳登录页；抓包确认先调 `/api/auth/token` 再重试原请求。
19. 401 恢复：在服务端吊销 refresh token 后操作页面，确认回到登录页且本机令牌被清除；重新登录可恢复。
20. 退出登录：设置 → 账户 → 退出登录，确认回到登录页；重开 App 仍为未登录；演示账户登录 / 切换 / 添加账户仍可正常使用。
21. 账号服务器地址：登录页底部或 设置 → 账户 → 账号服务器 改成可访问的测试地址，确认「测试并保存」生效；填非法地址（缺 scheme / 带查询串）确认有校验提示；「恢复默认地址」回到 `https://flux.qiuli55.top`。
